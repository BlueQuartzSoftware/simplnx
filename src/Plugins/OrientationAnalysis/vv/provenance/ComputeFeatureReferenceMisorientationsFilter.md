## How it was generated

The retired archive's pipeline reads `T12-MAI-2010/fw-ar-IF1-aptr12-corr.ctf`, crops the EBSD data, segments features and calculates reference misorientations in SIMPLNX. The archive ReadMe records Michael Jackson's manual review for reasonableness on 2026-01-14. Its generating pipeline and ReadMe are at `vv_work:ComputeFeatureReferenceMisorientationsFilter/scratch/compute_feature_reference_misorientation/compute_feature_reference_misorientation.d3dpipeline` and `vv_work:ComputeFeatureReferenceMisorientationsFilter/scratch/compute_feature_reference_misorientation/ReadMe.md`. This archive is separate from the Small IN100 input used in the legacy comparison.

Current inputs are built by `AnalyticalFixtures::CreateScaffold()` in `src/Plugins/OrientationAnalysis/test/ComputeFeatureReferenceMisorientationsTest.cpp`. The six analytical fixtures and invariant sweep were added in PR #1629. Pure c-axis rotations encode known misorientation angles; hand-selected grain-boundary distances specify the reference cells. The fixture origin is zero and spacing is one, so a cell index `(x,y,z)` has center `(x+0.5,y+0.5,z+0.5)`.

| Fixture | Dimensions | Independent expectation |
|---|---|---|
| `Class 1 - Mode 0 SingleGrainIdentity` | 2×2×2 | Identity orientations give zero angles and means. |
| `Class 1 - Mode 0 KnownAngle5deg` | 2×2×2 | Every cell is 5° from its feature reference; the mean is 5°. |
| `Class 1 - Mode 0 MultiGrain EdgeCases` | 4×3×1 | Cell angles are `[0,5,5,0,0,5,0,0,0,0,0,0]`; feature means are `[0,5,0,5,0]`. |
| `Class 1 - Mode 1 KnownCenter` | 3×3×1 | Center is `(1.5,1.5,0.5)`; its angle is zero and eight other cells have 5° angles. |
| `Class 1 - Mode 1 MultiGrain CenterIsolation` | 2×3×1 | Centers are `(1.5,0.5,0.5)` and `(1.5,2.5,0.5)`; each mean is 10/3°. |
| `Class 1 - Mode 1 3D Volume` | 3×3×2 | Center is `(1.5,1.5,1.5)`; its angle is zero and 17 cells have 5° angles. |
| `Class 4 - Invariants Sweep` | Two 3×3×1 configurations | Angles are nonnegative and at most 62.8° for cubic symmetry; skipped cells and background stay zero; feature means equal participating-cell sums/counts. |
| `genuine HDF5 65536-block tail oracle` | 65537×1×1 | Literal cell angles and means cover both modes; a tied reference at the final cell has center `(65536.5,0.5,0.5)`. |

The analytical angle tolerance is 0.001°. Center checks use a margin of 0.00001. The feature-mean invariant uses a tolerance of 0.0001°. These fixtures check the filter's reference selection and averaging; their symmetric orientations do not cover every crystal symmetry or a nonzero geometry origin.

**Legacy comparison evidence**

The run against DREAM.3D v6.5.171 on 2026-09-17 used SIMPLNX `8b80721c20853d891d5040f9134315af1d93b2b6` and the stock application PipelineRunner 1.2.828. Three of three direct Mode 0 analytical fixtures agree with their independent expected angles within 0.001°. Only the identity fixture is bit-identical between the two applications. All four direct Mode 1 cases crash in DREAM.3D v6.5.171; all complete in SIMPLNX and in a local proof version with the feature-count correction.

| Comparison | Result recorded on 2026-09-17 |
|---|---|
| Direct analytical Mode 1, local proof version versus SIMPLNX | Three of three fixtures match exactly for both misorientation arrays. |
| Small IN100 Mode 0, DREAM.3D v6.5.171 versus SIMPLNX | Maximum cell difference 0.07380°; maximum feature difference 0.01761°. |
| Small IN100 Mode 0, local proof version versus SIMPLNX | Maximum cell difference 1.907e-6°; maximum feature difference 1.669e-5°. |
| Small IN100 Mode 1, local proof version versus SIMPLNX | Maximum cell difference 9.537e-7°; maximum feature difference 6.437e-6°. |
| Mode 1 emulation versus direct SIMPLNX Mode 1 | Four of four cases match exactly for both misorientation arrays. |

The emulation independently selects the last cell with the maximum distance, places its quaternion in AvgQuats, and runs Mode 0. The comparison script reproduces each application's stored feature means with its own accumulation order. Thus, the remaining average differences are consistent with float32 summation order.

Evidence is at `vv_work:ComputeFeatureReferenceMisorientationsFilter/ReadMe.md`, `vv_work:ComputeFeatureReferenceMisorientationsFilter/comparison/results.md`, `vv_work:ComputeFeatureReferenceMisorientationsFilter/comparison/results.json`, `vv_work:ComputeFeatureReferenceMisorientationsFilter/comparison/run_exit_codes.txt` and `vv_work:ComputeFeatureReferenceMisorientationsFilter/comparison/mode1_emulation_results.md`. Input generators are `vv_work:ComputeFeatureReferenceMisorientationsFilter/scripts/generate_fixture_inputs.py`, `vv_work:ComputeFeatureReferenceMisorientationsFilter/scripts/generate_smallin100_input.py` and `vv_work:ComputeFeatureReferenceMisorientationsFilter/scripts/generate_mode1_emulation_inputs.py`.

Commit `4ec21e93f` (2026-09-20, PR #1568) changes the algorithm after this comparison. It adds block reads, cached references, participating phase/Laue checks and background exclusion during center selection. A comparison with the current algorithm is required.
