## How it was generated

The archive was produced by a legacy DREAM3D pipeline that is **embedded in the `.dream3d` file
itself** (`/Pipeline/Pipeline`), so the provenance is self-documenting even though no external
`.d3dpipeline` was preserved. It is a 43-step pipeline: read Small IN100 from `SmallIN100.h5ebsd`,
perform a standard reconstruction and segmentation, crop, and then run the full feature-statistics
suite.

The steps that produce this filter's exemplars:

| Step | Filter | `FilterVersion` |
|---|---|---|
| 29 | `FindFeatureCentroids` | 6.6.373 |
| 31 | `FindShapes` | 6.6.373 |

Surrounding steps (`FindSizes`, `FindNeighbors`, `FindNeighborhoods`, `FindEuclideanDistMap`,
`FindSurfaceAreaToVolume`, `FindMisorientations`, `FindSchmids`,
`FindFeatureReferenceMisorientations`, `FindKernelAvgMisorientations`) are all `6.6.373`; the
`DataContainerReader`/`Writer` and `MultiThresholdObjects` steps report `2.0.498`.

## Oracle provenance detail

### Class 2 — Reference implementation

- **Reference:** legacy SIMPL `FindShapes`, SIMPL UUID `3b0ababf-9c8d-538d-96af-e40775c4f0ab`
- **Exact version:** `FilterVersion 6.6.373`, recorded in the embedded pipeline
- **Runner:** legacy DREAM3D `PipelineRunner` (`DataContainerWriter` at step 42)
- **Pipeline file:** not preserved externally; embedded at `/Pipeline/Pipeline`
- **Input dataset:** cropped Small IN100 (`SmallIN100.h5ebsd`), not synthetic

**Full-array verification performed during the V&V cycle.** `UnitTest::CompareDataArrays`, which
the unit test uses, breaks out of its loop at the first index where two values differ *at all* and
only sets `failed` when that first difference exceeds `EPSILON = 1e-4` absolute — so elements after
the first difference are never examined. To close that gap, `ComputeShapesFilter` was run through
`nxrunner` on the archive's own geometry, `FeatureIds` and `Centroids`, and every element was
diffed with `h5py` (`ww_work/ComputeShapes/results_archive_check.txt`):

| Array | Elements exactly equal | max abs diff | max rel diff |
|---|---|---|---|
| `Omega3s` | 620 / 620 | 0 | 0 |
| `AxisLengths` | 1860 / 1860 | 0 | 0 |
| `AspectRatios` | 1240 / 1240 | 0 | 0 |
| `Shape Volumes` | 620 / 620 | 0 | 0 |
| `AxisEulerAngles` | 1626 / 1860 | 4.8e-7 | 3.5e-7 |

Four of the five arrays are bit-identical across all 620 features; the fifth differs only at the
float32 noise floor of the eigenvector-to-Euler chain. This is a genuine Class 2 oracle, not a
circular one.

**Baseline caveat, and why it is informative rather than a weakness.** The `6_6_` prefix and the
`6.6.373` filter version mean this exemplar comes from a legacy build *later* than the 6.5.171
baseline the V&V cycle compares against, so the archive alone is not a 6.5.171 comparison — that
comparison of record is the nine-fixture `PipelineRunner` A/B run documented in the V&V report.
But the bit-exact agreement above is itself load-bearing evidence: the corner-sampling defect
`ComputeShapesFilter-D3` changes 3D results by 5% to 50% relative on features of this size, so a
6.6.373 build that agrees with SIMPLNX to the last bit must already sample voxel **centers**. The
defect is therefore specific to the 6.5.x line, and the later legacy line and SIMPLNX agree. The
6.6.373 source was not available for inspection, so this is executed evidence rather than a source
reading.

**Coverage caveats.**

- Isotropic spacing (`0.25, 0.25, 0.25`) — the archive cannot discriminate any spacing-dependent
  defect, including two of the three `m_ScaleFactor` branches and the whole of
  `ComputeShapesFilter-D2`.
- Fully three-dimensional (`80 x 80 x 117`) — it never enters the 2D path, so it is blind to
  `ComputeShapesFilter-D1` and `-D2` and to the `pi/180`-for-`pi/2` transcription regression.
  Verified by mutation: reverting any of those three fixes leaves this test passing.
- Only feature id 0 has zero volume, so it cannot exercise the empty-feature path.

These are exactly the gaps the nine analytical fixtures in `ComputeShapesFilterTest.cpp` exist to
close. Do not treat this archive as sufficient coverage on its own.
