## How it was generated

`AnalyticalFixtures::CreateScaffold()` constructs a synthetic image with one cell per real Feature and a background Feature at index zero. It supplies explicit quaternions, phases, unit volumes, and contiguous and non-contiguous neighbor lists. The five analytical fixtures use hand-derived expectations; no computed filter output supplies their expected groups.

The image dimensions are `{numFeatures - 1, 1, 1}`, spacing is `{1, 1, 1}`, and origin is `{0, 0, 0}`. Geometry does not enter the grouping calculation. The cell-to-Feature mapping exists to check the final parent assignment. Three ensemble entries represent the background sentinel, hexagonal-high, and cubic-high classes. The background has phase zero and no cell assigned to it. All Features have unit volume; these fixtures do not distinguish unequal volume weights.

`QuatFromPhiDeg()` stores `{sin(Phi/2), 0, 0, cos(Phi/2)}` in x/y/z/w order. For these pure-Bunge rotations, the sample-frame c-axis is `(0, sin(Phi), cos(Phi))`. The c-axis angle is the difference between the selected Phi values, folded for antipodal equivalence. Current fixtures stay in one hemisphere, so they do not exercise antipodal acceptance.

| Fixture | Inputs and independent expectation |
|---|---|
| Pure-Phi Bunge | F1 through F5 have Phi values 0, 5, 60, 63, and 25 degrees. Edges connect F1–F2–F3–F4; F5 is isolated. At 10 degrees, expected groups are `{F1,F2}`, `{F3,F4}`, and `{F5}`. |
| RandomizeParentIds invariants | Three copies of the five-Feature fixture run with seed 42. One disables label randomization and two enable it. All preserve group membership and cell mapping; the two randomized outputs agree exactly. At least one real-Feature label must change relative to the unshuffled run. |
| Tolerance Boundary | A 0/8/20-degree chain at 10-degree tolerance gives `{F1,F2}` and `{F3}` with touching-Feature comparison. The two relevant separations are 8 and 12 degrees. This is not an exact floating-point boundary test. |
| Running Average | A 0/9/18-degree chain with unit volumes at 10-degree tolerance gives two groups. After one pair joins, its average is 4.5 or 13.5 degrees; the remaining end differs by 13.5 degrees. The test executes seed 42 and asserts the group count and membership constraints. |
| Mixed-Laue Rejection | Twenty isolated pairs each contain one cubic-high and one hexagonal-high Feature. Their c-axes align. Running-average mode must reject every pair because the reference and candidate must both be hexagonal-high. |
| Non-contiguous neighbor grouping | Two Features at 0 and 2 degrees have empty contiguous lists and mutual non-contiguous links. At 10 degrees, they must share a parent. |
| Default contiguous-only neighbor mode | Two Features at 0 and 2 degrees have mutual contiguous links. The test checks successful preflight and execution with optional neighbors disabled. It does not check the output parent values. |
| Phase Index Bounds | Three real Features include one touching pair and one isolated Feature. Separate sections assign an out-of-range positive phase to each touching Feature and expect `-87001`. An invalid phase on the isolated Feature permits execution. |

The unused `BuildLargeBenchmarkFixture()` helper does not define an executing test case and does not supply full-batch coverage.

## Oracle provenance (Classes 2, 3, 5 only)

Not applicable to the correctness oracle. Classes 1 and 4 live in the test source. The following local proof comparison supplies separate migration evidence.

`vv_work:GroupMicroTextureRegionsFilter/ReadMe.md` dates the comparison to 2026-08-27. The runnable legacy implementation was a local proof version. DREAM.3D v6.5.171 could not instantiate this private filter. The production input came from `915C_50red Data.h5oina`: 2,326,310 cells, 1,840,838 Feature tuples, and 3,710,475 undirected touching pairs. `vv_work:GroupMicroTextureRegionsFilter/to_legacy.py` records the format conversion. The filter inputs were identical in the two file formats.

The comparison used a 20-degree tolerance and disabled non-contiguous neighbors. The final proof patch used one seeded generator, checked both Laue classes, used float32 tolerance conversion, and disabled the final parent-ID shuffle. The patch is `vv_work:GroupMicroTextureRegionsFilter/notes/legacy_exact_parity.patch`.

The initial comparison without proof corrections matched partitions when running average was disabled, but not raw labels. With running average enabled, it had 198,626 differing touching-pair decisions, including 923 cross-Laue pairs. The first proof correction removed cross-Laue disagreements but left two hexagonal/hexagonal differences at seed 5489. Separate preserved experiments had 194,658 differing pairs between repeated executions and 192,496 between selected seeds. All were hexagonal/hexagonal, with no cross-Laue differences. These counts describe those runs, not every seed choice. Source: `vv_work:GroupMicroTextureRegionsFilter/rerun/preserved_seed_variation_results.txt`.

The production comparison used SIMPLNX `42287fe556f7b696ffd93e1d024d819a9aba02b7`; the final V&V source is recorded as `c89e05cb9524d92e9f77681cb897b8653b18781d`. Two later commits change the algorithm source: `4ec21e93f` (2026-09-20, PR #1568: buffered Feature data, cell mapping, and phase bounds) and `a33c370ca` (2026-09-25, PR #1697: messaging API). The 2026-08-27 comparison therefore does not establish parity for the current algorithm.

| Scenario | Review result |
|---|---|
| Neighbor-chain growth | The selected comparison target determines whether the entire chain joins. Both targets should be available. |

The review request incorrectly stated that the legacy running-average option never grouped grains. The reviewer reported successful use, and the source confirms that D3 weakens the Laue check rather than preventing grouping. The review also requests non-contiguous neighbor support; `Non-contiguous neighbor grouping` now asserts that path's output.
