## How it was generated

PR #1462 states that the test data was generated from SIMPLNX output. Its test reads `read_ang_test.ang` and compares cell arrays with `read_ang_test.dream3d`; two further ANG files supply invalid-phase and truncated-data inputs. The current replacement constructs synthetic ANG text in `src/Plugins/OrientationAnalysis/test/ReadAngDataTest.cpp` and derives expected values directly from that text.

The base fixture has dimensions `(3, 2, 1)`, spacing `(0.25, 0.5, 1)`, and cubic Nickel and hexagonal Titanium phase sections. Its Euler components and cell columns distinguish axes and components. The origin is zero because the filter fixes it at zero. Most cell values are exactly representable in float32; lattice constants such as 3.52, 2.95 and 4.68 use the corresponding float32 literals, not exact binary fractions. A phase-2-only header checks unused ensemble slots. Separate header and data variants check five errors.

Releases through v7.4.1 allocate `phaseCount + 1` tuples, write phase indices without bounds checks and copy reader buffers without a count guard. The v7.4.2 sources contain all three guards and `max(maxPhaseIndex, phaseCount) + 1` allocation. They establish that D3 and D6 are fixed in DREAM3D-NX v7.4.2.

DREAM.3D v6.5.171 was affected by D3 and D6. Its tagged `Source/Plugins/OrientationAnalysis/OrientationAnalysisFilters/ReadAngData.cpp` uses count-based ensemble allocation and unchecked indexed writes and buffer copies. Its tagged `Source/EbsdLib/TSL/AngReader.cpp` uses even columns for geometry and positive odd columns first for square-grid buffer allocation. These sources also confirm the material-name, unit, error-code and phase-0 differences D1, D2, D4 and D5.

## Canonical oracle output

The retired archive is not a correctness oracle. These paths identify the current inline expectations under `DataContainer`.

| DataPath | Source of expected values |
|---|---|
| `/DataContainer` | Class 1 header dimensions and spacing, zero origin and Micrometer units. |
| `/DataContainer/CellData/Phases` | Class 1 remap of `{1,2,0,1,2,0}` to `{1,2,1,1,2,1}`. |
| `/DataContainer/CellData/EulerAngles` | Class 1 interleave of the three written angle columns, in file order. |
| `/DataContainer/CellData/{Image Quality,Confidence Index,SEM Signal,Fit,X Position,Y Position}` | Class 1 literal values copied from the fixture columns. |
| `/DataContainer/CellEnsembleData/CrystalStructures` | Class 1 symmetry mapping: `{999,1,0}` for the two-phase fixture and `{999,999,0}` for the sparse fixture. |
| `/DataContainer/CellEnsembleData/MaterialName` | Class 1 trimmed names and Class 4 `Invalid Phase` defaults for unused slots. |
| `/DataContainer/CellEnsembleData/LatticeConstants` | Class 1 header constants and Class 4 zero defaults for unused slots. |

The eight ordinary test cases cover these expectations, the five errors and SIMPL conversion. All pass in CI at `419f9db35` on Linux, macOS and Windows, using in-core builds. The current filter, algorithm and test file match that revision. The hidden block-boundary case defines a 65,537-point fixture and checks the final point of a full block and its one-point tail.
