## How it was generated

The regression tests read `segment_features_test_data/segment_features_test_data.dream3d`. They select Quats, Phases and Mask (Y Pos) from `DataContainer/CellData`, and CrystalStructures from `DataContainer/CellEnsembleData`. Four stored label arrays supply regression expectations for face or all-connected neighbors, with or without the mask. Generation authorship and commit above follow the first archive registration.

The separate analytical fixtures are constructed in `src/Plugins/OrientationAnalysis/test/CAxisSegmentFeaturesTest.cpp`. `AnalyticalFixtures::CreateScaffold()` builds Image geometry, and `QuatFromPhiDeg()` supplies hand-selected pure-Phi orientations. The RectGrid fixture builds unequal X intervals directly. The hidden `Generate Test Data` case writes synthetic inputs; it does not compute canonical labels.

The legacy comparison inputs come from `vv_work:CAxisSegmentFeaturesFilter/scripts/make_inputs.py`. That script writes shared legacy-format data for ten cases; `vv_work:CAxisSegmentFeaturesFilter/scripts/make_pipelines.py` constructs their pipelines. `vv_work:CAxisSegmentFeaturesFilter/scripts/compare_matrix.py` compares partitions after replacing labels by first-occurrence order.

## Canonical oracle output

Classes 1 and 4 provide the independent correctness expectations in the C++ test source. The archive arrays are regression references.

| DataPath | Source of expected values |
|---|---|
| `ImageGeometry/CellData/FeatureIds` | Class 1: pure-Phi folded angles, equal positive phases, mask values and grid adjacency. Eight analytical cases assert exact labels. |
| `ImageGeometry/CellFeatureData/Active` | Class 4: N + 1 tuples for N real features, Active[0] = 0 and every real feature active. |
| `ImageGeometry/CellData/FeatureIds` after randomization | Class 4: unchanged partition, IDs 1 through N without gaps, deterministic relabeling and masked zeros preserved. |
| `DataContainer/CellData/CAxis_FeatureIds_Face` | Archive regression reference; the test also requires 57 Active tuples. |
| `DataContainer/CellData/CAxis_FeatureIds_All` | Archive regression reference; the test also requires 37 Active tuples. |
| `DataContainer/CellData/CAxis_FeatureIds_Mask_Face` | Archive regression reference; the test also requires 31 Active tuples. |
| `DataContainer/CellData/CAxis_FeatureIds_Mask_All` | Archive regression reference; the test also requires 25 Active tuples. |

For the pure-Phi fixtures, quaternions are `(sin(Phi/2), 0, 0, cos(Phi/2))`. Their c-axes are `(0, ±sin(Phi), cos(Phi))`, and the test angles give folded distance `min(abs(ΔPhi), 180° − abs(ΔPhi))`. The 3×2×2 fixture uses different orientation values along each axis; the phase fixture uses both hexagonal classes. Physical origin and spacing do not enter the adjacency or angle calculation.

All 28 ordinary test cases pass in CI at `419f9db35`. The hidden input generator is listed separately in the report.

## Oracle provenance (Classes 2, 3, 5 only)

Not applicable. Classes 1 and 4 are encoded in the test source. The following release comparison explains migration behavior and does not define the correctness oracle.

Run against DREAM.3D v6.5.171 on 2026-09-17: 6 of 6 valid shared Image cases match DREAM3D-NX v7.4.2 at the partition level and have equal feature counts. These are TC1 through TC6. Both applications return `-87000` for all-masked TC10. DREAM3D-NX v7.4.2 rejects out-of-range phase TC7 and non-hexagonal TC9, while DREAM.3D v6.5.171 writes segmentations. RectGrid TC8 is a SIMPLNX-only case.

`vv_work:CAxisSegmentFeaturesFilter/ReadMe.md` identifies the official DREAM.3D v6.5.171 PipelineRunner. `vv_work:CAxisSegmentFeaturesFilter/comparison/comparison_results.md` gives every result; `vv_work:CAxisSegmentFeaturesFilter/comparison/run_matrix.json` records the runner executions. Repeated legacy runs change raw labels while preserving partitions. A local proof version with randomization disabled matches v7.4.2 raw labels on all six valid shared Image cases.

Release exposure comes from the source at each `upstream/release/v<version>` branch: v7.0.0, v7.0.1, v7.0.2, v7.0.3, v7.2.0, v7.2.1, v7.2.2, v7.4.0, v7.4.1 and v7.4.2. Legacy source is the DREAM.3D `v6.5.171` tag, `Source/Plugins/Reconstruction/ReconstructionFilters/CAxisSegmentFeatures.cpp` and `SegmentFeatures.cpp`. SIMPL validation uses commit `0afaa6854`, the last commit before the tag date, in `Source/SIMPLib/DataContainers/DataContainerArray.h`.
