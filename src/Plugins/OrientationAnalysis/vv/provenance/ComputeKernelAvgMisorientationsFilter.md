## How it was generated

The shared archive contains Small IN100 reconstruction data and stored filter outputs. Current KAM tests instead call `AnalyticalFixtures::CreateScaffold()` in `src/Plugins/OrientationAnalysis/test/ComputeKernelAvgMisorientationsTest.cpp` to construct an Image Geometry, cell arrays and an ensemble array. `QuatFromPhi1Deg()` constructs `(0,0,sin(φ1/2),cos(φ1/2))` quaternions from specified angles. Expected values come from hand averages and invariants, independently of filter output.

The base Class 1 and Class 4 fixtures replace the archive consumer in `ec22ac375` (PR #1631). `a96b48332` (PR #1674) adds the same-phase mode fixtures. `4ec21e93f` (PR #1568) adds memory-planning, phase/Laue bounds, maximum-radius, empty-image and bounded-cache checks.

**Fixture construction**

| Item | Definition |
|---|---|
| Geometry | `ImageGeometry`, dimensions supplied by each fixture, spacing `{1,1,1}`, origin `{0,0,0}`. |
| Cell group | `ImageGeometry/CellData`, tuple shape `{nZ,nY,nX}`. |
| Cell arrays | `FeatureIds` and `Phases`: int32, one component; `Quats`: float32, four components in `(x,y,z,w)` order. |
| Ensemble group | `ImageGeometry/EnsembleData`; `CrystalStructures` defaults to `[999,1]`, with cubic phase one. |
| Two-phase fixture | `CrystalStructures=[999,1,1]`; the two phase IDs share cubic symmetry but remain distinct phase labels. |
| Output | `ImageGeometry/CellData/KernelAverageMisorientationsOut`, float32, one component, in degrees. |

The X and Z line fixtures use different dimensions and radii to distinguish axis indexing. The multi-feature fixtures distinguish feature IDs and phase IDs. Geometry origin does not enter the kernel calculation; it uses integer cell coordinates and radii.

**Analytical derivation**

All analytical orientations are pure Z rotations. Cubic symmetry reduces their angular difference modulo 90°. The fixture differences are at most 40°, so the minimum angle is `|Δφ1|`. For each focal cell, sum the admitted angles and divide by the admitted cell count, including the focal cell's zero contribution.

The X gradient uses angles `[0,5,10,15,20]°`. Each endpoint includes itself and one neighbor, giving `5/2°`. Each interior cell includes two 5° differences and itself, giving `10/3°`.

The Z gradient uses `[0,10,20]°`. The endpoints give `10/2=5°`; the middle gives `(10+0+10)/3=20/3°`.

The six-cell fixture uses feature IDs `[1,1,2,2,0,1]`, phases `[1,1,1,1,0,1]`, and angles `[0,10,0,20,0,30]°`. The background angle is irrelevant. The following table shows the admitted angle sums and divisors in both modes.

| Cell | Same-feature calculation | Same-phase calculation |
|---|---|---|
| 0 | `(0+10)/2=5` | `(0+10)/2=5` |
| 1 | `(10+0)/2=5`; reject cell 2 | `(10+0+10)/3=20/3`; admit cell 2 |
| 2 | `(0+20)/2=10`; reject cell 1 | `(10+0+20)/3=10`; admit cell 1 |
| 3 | `(20+0)/2=10`; reject background | `(20+0)/2=10`; reject background |
| 4 | Invalid focal feature: exactly zero | Invalid focal feature: exactly zero |
| 5 | Self only: zero | Self only: zero |

The two-phase fixture uses feature IDs `[1,2,3,4,0]`, phases `[1,1,2,1,1]` and angles `[0,10,20,30,40]°`. Cells 0 and 1 admit each other and give 5°. Cell 2 rejects both adjacent phase-one cells. Cell 3 rejects phase two and background. Cell 4 is invalid despite its positive phase.

The full-depth fixture uses slice angles `[0,5,10,15,20]°` in one feature. Each kernel includes all five slices at the same X/Y coordinate. The angle sums are `[50,35,30,35,50]°`; division by five gives `[10,7,6,7,10]°`.

The gradient and mixed-feature assertions use a 0.001° margin. Uniform-zero assertions use 0.0001°. Background-zero assertions require exact equality.

**Class 4 invariants**

`Class 4 - Invariants` checks uniform zero, exact background zero, nonnegative KAM, the 62.8° cubic bound and a nonzero result on the X gradient. `Class 4 - Mode Equivalence on Single Feature` constructs a 3×3×3 gradient with `φ1=2x+3y+4z` degrees. Both modes admit the same neighbors, so every output must match bit-for-bit; a nonzero guard prevents an all-zero result from satisfying the comparison.
