## How it was generated

`curated::CreateTestDataStructure()` constructs a synthetic mesh with 111 vertices, 37 faces, 45 feature tuples and 13 ensemble tuples. Each Laue class has four feature orientations, with Euler angles `(0,0,0)`, `(45,0,0)`, `(90,0,0)` and `(180,0,0)` in degrees. The test runs `ChangeAngleRepresentationFilter` to convert degrees to radians and `ConvertOrientationsFilter` to create quaternions. Expected output angles are literal analytical values in the test; they are not computed from filter output.

Feature 0 is a sentinel. Features 1–44 form 11 groups of four, with phases 1–11 and Laue indices 0–10. Ensemble tuple 0 contains 999; tuple 12 repeats Laue index 10 and is unused by the curated faces. Faces 0–29 contain the first ten classes, faces 30–33 contain two background and two mixed-phase cases, and faces 34–36 contain Trigonal_High. Each triangle has three separate vertices; the angle algorithm reads face labels and feature data, so vertex positions do not determine the expected angles.

`Phase Index Bounds` constructs one face with labels 1 and 2, three feature tuples and two ensemble tuples. Its sections use phases `(2,2)` and `(2,1)` to check the error and skip paths. The hidden boundary fixture constructs 65,537 faces and places analytical 15° and 30° values at tuples 65,535 and 65,536. PR #1568 (`4ec21e93f`) adds the bounds fixture; PR #1750 (`8914ca68f`) adds the boundary fixture.

Run against DREAM.3D v6.5.171 on 2026-09-17: 639,631 of 640,880 comparable faces match within 0.0001°. The run predates algorithm commit `4ec21e93f` (2026-09-20, PR #1568), which adds phase validation and changes the placement of the Crystal Structures lookup. These archived results describe the algorithm used on the run date.

`vv_work:ComputeFeatureFaceMisorientationFilter/ReadMe.md` identifies the stock application and its `SIMPLib Version 1.2.828.f45085c83` banner. `vv_work:ComputeFeatureFaceMisorientationFilter/comparison/summary.md` and `vv_work:ComputeFeatureFaceMisorientationFilter/comparison/difference_report.md` record the results below. The comparison takes the float64 Euclidean norm of the legacy axis-times-angle vector and compares it with the SIMPLNX scalar angle on valid same-phase Hexagonal_High and Cubic_High faces.

A local proof version matches all 640,880 comparable faces within 0.0001°. All 120,154 invalid faces give SIMPLNX NaN and legacy zero vectors; all 127 faces in classes unsupported by the legacy filter give finite SIMPLNX values and legacy zero vectors. These checks explain migration differences; the independent correctness oracle remains the analytical test source.

`vv_work:ComputeFeatureFaceMisorientationFilter/scripts/make_inputs.py` defines the comparison inputs. `vv_work:ComputeFeatureFaceMisorientationFilter/scripts/compare.py` defines the magnitude mapping and tolerances. `vv_work:ComputeFeatureFaceMisorientationFilter/comparison/audit.json` records input-array checks and comparison counts. The random input uses a saved payload because the original generator did not reproduce it; its claimed 400 zero-angle pairs are nonzero and do not define an analytical zero-angle oracle.

## Canonical oracle output

| DataPath | Source of expected values |
|---|---|
| `/triangle_geom/FaceData/NXFaceMisorientationColors` | Class 1 symmetry reduction: 33 literal angles and four NaN checks in `Curated Data`. |
| `/Bounds Data/Bounds Misorientations` | Mixed phases give NaN; a shared out-of-range phase returns `-98412` before angle calculation. |

For each class, reduce a pure c-axis rotation by its allowed rotational symmetries. The expected angles below are in degrees. This table preserves the analytical derivation from the report and matches the test literals.

| Laue class | Index | 45° input | 90° input | 180° input |
|---|---:|---:|---:|---:|
| Hexagonal_High | 0 | 15 | 30 | 0 |
| Cubic_High | 1 | 45 | 0 | 0 |
| Hexagonal_Low | 2 | 15 | 30 | 0 |
| Cubic_Low | 3 | 45 | 90 | 0 |
| Triclinic | 4 | 45 | 90 | 180 |
| Monoclinic | 5 | 45 | 90 | 180 |
| OrthoRhombic | 6 | 45 | 90 | 0 |
| Tetragonal_Low | 7 | 45 | 0 | 0 |
| Tetragonal_High | 8 | 45 | 0 | 0 |
| Trigonal_Low | 9 | 45 | 30 | 60 |
| Trigonal_High | 10 | 45 | 30 | 60 |

The curated angle checks require an absolute error below 0.000012°. Faces 30–33 use `std::isnan`. Thus the test checks 37 face values in total, not 37 angles plus four NaN values. The cubic 90° case must reduce to zero because that rotation is a cubic symmetry operation. The Trigonal_Low and Trigonal_High fixtures both reduce by 120° rotations about c.
