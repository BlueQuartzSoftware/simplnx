## Canonical oracle output

The paths below identify C++ fixture arrays, not archived filter outputs. Quaternion components use `(x,y,z,w)` order.

| DataPath | Source of expected values |
|---|---|
| `/ImageGeom/Cell Feature Data/AvgQuats` | Class 1 hand-derived means; Class 4 unit norm, nonnegative scalar component, cubic symmetry and two-ordering checks. |
| `/ImageGeom/Cell Feature Data/AvgEulerAngles` | Identity and empty features give zero; pure z rotations have finite components and middle Euler angle zero. |
| `/ImageGeom/Cell Feature Data/vMF Avg Quats`, `/ImageGeom/Cell Feature Data/vMF Kappas` | Class 2 fixed EbsdLib VMF estimates; Class 4 single-sample and empty-feature rules. |
| `/ImageGeom/Cell Feature Data/Watson Avg Quats`, `/ImageGeom/Cell Feature Data/Watson Kappas` | Class 2 fixed EbsdLib Watson estimates; Class 4 single-sample and empty-feature rules. |
| `/ImageGeom/Cell Feature Data/vMF Avg EulerAngles`, `/ImageGeom/Cell Feature Data/Watson Avg EulerAngles` | Class 4 empty-feature NaN assertions; multi-sample cases also compare Direct and Scanline values. |

For the triclinic fixtures, the selected quaternion representatives have positive scalar components. Their normalized sum gives the Rodrigues expectation. With `Rz(theta) = (0,0,sin(theta/2),cos(theta/2))`, the six feature fixtures are:

| Fixture | Input | Expected AvgQuats |
|---|---|---|
| F0 | One phase-zero cell | `(0,0,0,1)` |
| F1 | Identity | `(0,0,0,1)` |
| F2 | Rz90 | `(0,0,0.70710678,0.70710678)` |
| F3 | Identity and Rz90 | `(0,0,0.38268343,0.92387953)` |
| F4 | Three Rz90 samples | `(0,0,0.70710678,0.70710678)` |
| F5 | No cells | `(0,0,0,1)` |

For F3, `normalize(identity + Rz(alpha)) = Rz(alpha/2)`, using the sine and cosine half-angle identities. The quaternion tolerance is `1e-6`. Pure z rotations have nonunique outer Euler angles, so the test checks finite values and a zero middle angle instead of selecting one arbitrary outer-angle pair. The cubic invariant uses five symmetry/sign representations of Rz30 and expects `(0,0,0.25881905,0.96592583)` within `1e-5`.

Directional single-sample features return the fundamental-zone quaternion with kappa zero. Empty features keep NaNs. Phase-zero and out-of-range-phase cells are excluded. The directional methods use the phase of the highest-index cell with a positive, in-range phase; if that phase has an unsupported crystal structure, the feature remains NaN. Rodrigues selects symmetry separately for each contributing cell. The phase-order fixture checks this distinction.

All pass in CI at `419f9db35`.
