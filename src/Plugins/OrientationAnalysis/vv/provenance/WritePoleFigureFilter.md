## How it was generated

The archive supplies 502 hexagonal Ti orientations, phase IDs, a 251-of-502 mask, crystal structures and phase names. Tests load `Pole_Figure_Exemplars_v6/Pole_Figure_Exemplars_v6.dream3d` and use these arrays as inputs. Archive attribution comes from its first registration in `src/Plugins/OrientationAnalysis/test/CMakeLists.txt`; the archived comparison scripts are `vv_work:WritePoleFigureFilter/build_legacy_input.py`, `vv_work:WritePoleFigureFilter/gen_nx_pf.py` and `vv_work:WritePoleFigureFilter/gen_legacy_pf.py`. Those scripts reuse the orientation inputs and construct the legacy input container; they do not generate expected test outputs.

## Canonical oracle output

The tests do not read a stored image as the expected result. Three Class 4 fixtures compare outputs from paired parameter settings. The four default test cases, including SIMPL conversion, run in the supplied Linux, macOS and Windows in-core CI result. All pass in CI at `419f9db35`.

| DataPath | Source of expected values |
|---|---|
| `/<output geometry>/Cell Data/Phase_1` | Class 4: masking, basis convention, mode and marker radius must change more than 1% of RGB components. |
| `/<intensity geometry>/Cell Data/Phase_1_<011>` | Class 4: the two hexagonal basis choices must change more than 1% of basal-intensity pixels. The test does not measure an exact rotation angle. |
| `/Counts/Cell Data/Phase_1_001`, `Phase_1_011`, `Phase_1_111` | Class 1 encoded in the hidden `real HDF5 65536-block discrete-count oracle`: exact sums [12, 24, 16] and a complete 32×32 <001> histogram. |

The Class 1 fixture constructs its own inputs. Identity and a 45-degree Z rotation lie on opposite sides of the 65,536-tuple extraction boundary. A third orientation is masked out. The <001> image has four counts at (16,15), four cardinal equatorial counts and four diagonal counts after row reversal. This fixture is separate from the four default CI cases.

Run against DREAM.3D v6.5.171 on 2026-07-08: 4 of 4 hexagonal/cubic Color/Discrete cases match the expected pole-figure topology by visual review.
