## How it was generated

The archive contains **inputs only**: a single-phase set of 502 hexagonal (Ti, Laue class 6/mmm) orientations under `Imported Data/Eulers` (radians), `Imported Data/Phases`, a 251-of-502 `Imported Data/Mask`, and `EnsembleAttributeMatrix/CrystalStructures` + `PhaseNames`. There is **no baked pole-figure image** used as an oracle — pixel-level reproduction is owned and byte-tested by EbsdLib upstream (`PoleFigureCompositorTest::All_Laue_Classes`), and baking an image here would couple simplnx CI to EbsdLib byte-identity (the prior v5 baseline-drift failure mode).
