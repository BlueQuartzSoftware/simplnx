## How it was generated

The archive contains a single NX-format `neighbor_orientation_correlation_v2.dream3d` with one
data container, `Exemplar Data`, holding the Small IN100 cell data after the standard
pre-processing chain (MultiThresholdObjects → ConvertOrientations → AlignSectionsMisorientation
→ IdentifySample → AlignSectionsFeatureCentroid → BadDataNeighborOrientationCheck) followed by
`NeighborOrientationCorrelationFilter` (MinConfidence 0.2, tolerance 5°, Level 2), exactly as
executed by the `Small IN100 Pipeline` test case. It was produced by a temporary write hook in
that test at the oracle-verified commit, with all containers other than `Exemplar Data`
stripped and the file h5py-repacked.

It replaces `neighbor_orientation_correlation.tar.gz` (retired 2026-07-06), whose container was
named `DataContainer` while the test looked up `Exemplar Data/...` — every array lookup
returned null and the comparison loop silently skipped, so **the v1 exemplar comparison never
compared any array** (hollow pass since 2022). The test now hard-fails on a missing or
type-mismatched exemplar array.

## Canonical oracle output

The canonical correctness oracle for this filter is **not** this archive — it is the 11 inline
Class 1/2 fixtures in `NeighborOrientationCorrelationTest.cpp` (`Oracle F01`–`F11`, `Class 4`
invariants), whose expected values are hand-derived (co-axial z-rotation regime) and
cross-checked by the NumPy reference implementation. This archive is a **regression pin** on
production-scale data.

## Regenerated to fix a circular-oracle situation?

Yes — with the circularity documented and mitigated. This archive's expected arrays are the
output of SIMPLNX **after** the D2 (pass schedule) and D3 (argmax selection) fixes, so it
cannot serve as an independent correctness oracle. Independence is provided by the 11 inline
oracle fixtures, on which the fixed SIMPLNX, the patched 6.5.172 proof build, and the Class 2
reference implementation agree exactly (bit-identical across all transferred arrays); this
archive only pins that verified behavior at production scale. The retired v1 archive
(`neighbor_orientation_correlation.tar.gz`) was never a functioning oracle (see above).
