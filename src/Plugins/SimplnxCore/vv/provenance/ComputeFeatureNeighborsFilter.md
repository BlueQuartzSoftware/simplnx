## How it was generated

PR #1124 replaced the shared statistics archive after correcting the voxel-center calculation in ComputeShapes. The neighbor regression loads `6_6_stats_test_v2.dream3d`, selects Small IN100 FeatureIds and compares three archived arrays. The independent analytical inputs and expectations are constructed in `src/Plugins/SimplnxCore/test/ComputeFeatureNeighborsTest.cpp` by the single-voxel, 1D, square 2D, non-square 2D and 3D builders.

The 11 analytical geometry fixtures expand to 35 ordinary cases. Eight dimensionality states use four optional-output combinations each; three non-square fixtures use both optional outputs. The ordinary inventory also includes one archive regression and one SIMPL conversion case. All pass in CI at `419f9db35` on Linux, macOS and Windows (in-core builds).

## Canonical oracle output

The archive supplies regression references, not the independent correctness oracle. The archive test compares `DataContainer/CellFeatureData/SurfaceFeatures`, `NumNeighbors` and `NeighborList`. It does not compare BoundaryCells or SharedSurfaceAreaList.

The canonical analytical expectations live in the test code:

| DataPath | Source of expected values |
|---|---|
| `Image/CellData/ExemplarBoundaryCells` | Class 1 count of faces touching a different positive feature |
| `Image/FeatureData/ExemplarSurfaceFeatures` | Class 1 boundary contact in active dimensions |
| `Image/FeatureData/ExemplarNumNeighbors` | Class 1 count of distinct positive neighbor IDs |
| `Image/FeatureData/ExemplarNeighborsList` | Class 1 sorted distinct neighbor IDs |
| `Image/FeatureData/ExemplarSharedSurfaceAreaList` | Class 1 sum of direction-specific face areas for each feature pair |

`ExecuteFilter()` compares the three required outputs and each requested optional output. The fixtures use zero origin; translation does not change adjacency or face area. Unequal spacings distinguish face directions, and the non-square 2D fixtures distinguish row strides.

All three variants use the same feature layout mapped to the appropriate active plane; expected output values are identical by symmetry.

**FeatureIds (EmptyZ, row=y outer, col=x inner):**

```
y=0: [1, 2, 2, 2, 1]
y=1: [2, 4, 2, 4, 2]
```

**Expected feature-level outputs:**

| Feature | SurfaceFeatures | NumNeighbors | NeighborList | SSA |
|---|---|---|---|---|
| 1 | true | 1 | {2} | {22.6} |
| 2 | true | 3 | {1, 3, 4} | {22.6, 6.8, 23.8} |
| 3 | false | 1 | {2} | {6.8} |
| 4 | false | 1 | {2} | {23.8} |
| 5 | true | 0 | {} | {} |

**SSA derivations (EmptyZ, face areas: X-normal=1.2, Y-normal=2.2):**

- **F2–F3 = 6.8:** F3 occupies only (x=2,y=2). Its four face neighbors are all F2: two X-normal contacts (1.2×2=2.4) + two Y-normal contacts (2.2×2=4.4) = 6.8.
- **F2–F4 = 23.8:** F4 occupies (1,1), (3,1), (1,3), (3,3). Each of the first three F4 voxels has all four face neighbors as F2 → 6.8 each. F4 at (3,3) has only two F2 contacts (right neighbor (4,3)=0 and down (3,4)=0 are background) → 1.2+2.2=3.4. Total: 3×6.8 + 3.4 = 23.8.
- **F1–F2 = 22.6:** F1 occupies (0,0), (4,0), (0,2), (4,2), (0,4), (2,4). Tracing F2-adjacent contacts per F1 voxel: (0,0)→3.4, (4,0)→3.4, (0,2)→5.6 [two Y-normal + one X-normal], (4,2)→3.4, (0,4)→3.4, (2,4)→3.4. Total: 22.6.

**SurfaceFeatures:** F3 and F4 are fully interior (no voxel touches any image edge) → false. F1, F2, F5 have boundary voxels → true.

**BoundaryCells:** Values range from 0 to 4. A count of 4 means that all four faces touch a different positive feature; those neighbor features need not be distinct from each other. `Fill2DImage()` contains all 25 expected values.
