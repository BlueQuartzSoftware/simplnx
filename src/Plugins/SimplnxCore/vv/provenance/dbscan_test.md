## How it was generated

The archive contains `7_0_2d_dbscan_test_data.dream3d` and `7_0_3d_dbscan_test_data.dream3d`, with XDMF companions. The script `vv_work:DBSCANFilter/dbscan_data_proj/plot_cluster_comparison.py` generates six synthetic 500-by-2 input datasets with scikit-learn and scales them with `StandardScaler`. SIMPLNX GDCF output from `LowDensityFirst` supplies the saved cluster labels; the 3D case uses epsilon 0.01 and minimum points 5. The 3D input source and generation script are not recorded.

PR #1421 added the archive registration on 2025-09-04. Its author identifies the inferred generator; the merge date does not give the archive generation date. The available local evidence does not give the date when that PR opened.

## Regenerated to fix a circular-oracle situation?

No. The archive retains the SIMPLNX-generated labels. The scikit-learn comparison checks aggregates for the six 2D inputs: four match and two have the documented GDCF difference. These comparisons support use of the 2D labels as regression fixtures; they do not independently verify every saved label. The 3D labels remain a circular oracle because no independent 3D comparison is recorded.
