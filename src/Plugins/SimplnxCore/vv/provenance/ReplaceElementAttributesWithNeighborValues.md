## Origin

The archive contains a single `6_6_replace_element_attributes_with_neighbor.dream3d` file generated by running a SIMPLNX pipeline against a Small IN100 subvolume and saving the **post-filter output**.

## Circular oracle — problem

The test loaded this file as both the filter input and the reference exemplar (both `baseDataFilePath` and `exemplarFilePath` pointed to the same path). Because the file contained post-filter data with all CI values already above the threshold, re-running the filter was idempotent (count=0, exits immediately) and the comparison passed trivially. The test confirmed only that the filter is stable on its own output — not that it correctly replaces bad voxels.

## Circular oracle — resolution

The consuming test was removed from `test/ReplaceElementAttributesWithNeighborValuesTest.cpp` on 2026-07-21. The synthetic test (`TEST_CASE "Synthetic neighbor replacement"`) provides a proper Class 1 + Class 4 oracle via `BuildSyntheticDataStructure()` that covers all 16 testable code paths. No replacement archive is needed.

The archive is unreferenced and may be retired from the Data_Archive release.

## Inlined test data — design and derivation

All test data is constructed inline in `test/ReplaceElementAttributesWithNeighborValuesTest.cpp` via `BuildSyntheticDataStructure(goodValue, badValue, badIndices)`. No external files are required.

### Geometry

3×3×3 `ImageGeom` (27 voxels). Linear index = `x + y*3 + z*9`. Two cell arrays:
- `Confidence Index` (float32) — the comparison array; initialized to `goodValue` everywhere, then `badValue` at each index in `badIndices`.
- `Marker` (int32) — a second array initialized to the linear index of each voxel. Its only role is to verify that the copy pass propagates **all** AttributeMatrix arrays, not just the comparison array.

### SECTION: LessThan / GreaterThan

`badIndices = {0, 13, 26}`. These three indices were chosen to cover all six boundary cases with the minimum voxel count:

| Index | Coordinates (x,y,z) | Boundary condition |
|-------|---------------------|--------------------|
| 0     | (0,0,0)             | Corner: -X, -Y, -Z all missing → only +X, +Y, +Z neighbors valid |
| 13    | (1,1,1)             | Fully interior: all 6 face neighbors valid |
| 26    | (2,2,2)             | Corner: +X, +Y, +Z all missing → only -X, -Y, -Z neighbors valid |

No two bad voxels are face-adjacent, so each bad voxel has at least one immediate good neighbor and the first loop iteration resolves all three.

**LessThan derivation** (`compare = val < threshold`, good=0.9, bad=0.1, threshold=0.5, loop=true):
- Each bad voxel (0.1 < 0.5) has ≥1 face neighbor at 0.9.
- `compare1(0.9, 0.5)` = `0.9 ≥ 0.5` = true; `compare2(0.9, best_init=0.1)` = `0.9 > 0.1` = true → `best` updated to 0.9.
- For subsequent good neighbors at 0.9: `compare2(0.9, 0.9)` = false → no further update (correct: equal neighbors are not "better").
- Copy pass: all three bad voxels become 0.9; `Marker[13]` becomes the Marker value of voxel 13's chosen neighbor (≠ 13).
- Second loop iteration: all 27 values ≥ 0.5 → count=0 → exits.

**GreaterThan derivation** (`compare = val > threshold`, good=0.1, bad=0.9, threshold=0.5, loop=true): symmetric. All three become 0.1 after one iteration.

**Asserted invariants:**
- LessThan: `∀i: confStore[i] >= 0.5` and `∀idx ∈ {0,13,26}: confStore[idx] == 0.9` and `markerStore[13] != 13`.
- GreaterThan: `∀i: confStore[i] <= 0.5` and `∀idx ∈ {0,13,26}: confStore[idx] == 0.1`.

### SECTION: loop=false

`badIndices = {13}` (center voxel only). With `loop=false`, exactly one scan+copy iteration runs. Voxel 13 has 6 good neighbors at 0.9; the first valid neighbor found sets `best=0.9` and `bestNeighbor[13]`. After the copy pass, `confStore[13] == 0.9`.

Asserted: `confStore[13] == Approx(0.9)`.

### SECTION: compare1=false skip

`badIndices = {4, 10, 12, 13, 14, 16, 22}` — center voxel 13=(1,1,1) plus its 6 face neighbors. `loop=false`.

The cluster indices map to:

| Index | Coordinates | Role |
|-------|-------------|------|
| 4     | (1,1,0)     | -Z neighbor of 13 |
| 10    | (1,0,1)     | -Y neighbor of 13 |
| 12    | (0,1,1)     | -X neighbor of 13 |
| 13    | (1,1,1)     | Center — target voxel |
| 14    | (2,1,1)     | +X neighbor of 13 |
| 16    | (1,2,1)     | +Y neighbor of 13 |
| 22    | (1,1,2)     | +Z neighbor of 13 |

**Derivation for voxel 13:** Every face neighbor is bad (0.1). For each, `compare1(0.1, 0.5)` = `0.1 ≥ 0.5` = false → `CompareValues` skips the neighbor. `bestNeighbor[13]` remains -1 throughout the scan pass. The copy pass skips voxel 13. `confStore[13]` remains 0.1.

**Derivation for ring voxels** (e.g., voxel 4=(1,1,0)): each has 4 good face neighbors outside the cluster (boundary or good-value voxels). At least one passes `compare1` → gets replaced with 0.9.

**Asserted:** `confStore[13] == Approx(0.1)` (unchanged); `∀idx ∈ {4,10,12,14,16,22}: confStore[idx] == Approx(0.9)` (replaced).

This section specifically exercises code path 11 in the coverage table: the `compare1=false` branch of `CompareValues` that skips a neighbor failing the threshold.
