## How it was generated

`CreateSequentialImageGeom()` builds synthetic Image Geometry fixtures with scalar Int32 values 1 through N. Hand-derived arrays specify the expected rotations; the tests also check dimensions, origins, spacing and value conservation. The separate legacy comparison uses `vv_work:RotateSampleRefFrameFilter/make_input.py` to write a shared 4×3×2 input with origin (0,0,0), spacing (1,1,1) and values 1 through 24. `vv_work:RotateSampleRefFrameFilter/gen_simpl_pipeline.py` and `vv_work:RotateSampleRefFrameFilter/gen_nx_pipeline.py` generate the four comparison pipelines for each application.
