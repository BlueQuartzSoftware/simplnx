## How it was generated

The `.dream3d` file stores the generating pipeline at `/Pipeline/Pipeline`. Its nested imported pipeline reads `6_5_test_data_1/6_5_test_data_1.dream3d`, copies `DataContainer` to `DataContainer2`, and sets the copy's origin to `[-10,50,30]` and spacing to `[0.5,0.5,0.5]`. The outer pipeline rebuilds all seven nonempty combinations of crop axes with feature renumbering enabled and writes the v2 file. Enabled crop axes use inclusive bounds `[10,15,0]` through `[60,40,50]`.

The archive supplies measured Small IN100 data, not synthetic expected removal output. The following input arrays retain their original values until the tests execute the filter.

## Canonical oracle output

No archive array is a golden removal output for RemoveFlaggedFeatures or RequireMinNumNeighbors. Those tests derive expectations from the input. Other consumers use the archived SurfaceFeatures, ConfidenceIndex, IPFColors and cropped geometries as regression references.

| DataPath | Source of expected values |
|---|---|
| `DataContainer/CellData/FeatureIds` | Class 1 literal IDs for the constructed fixtures; Class 4 surviving-ID and compaction checks for Small IN100 |
| `DataContainer/CellData/CellValue` | Class 1: start at `100 + cell index`; each filled value identifies its chosen neighbor |
| `DataContainer/CellData/IgnoredValue` | Class 1: start at `500 + cell index`; preserve values when ignored, otherwise copy the selected neighbor |
| `DataContainer/CellFeatureData/Int32DataSet` | Class 1: start at `1000 + feature ID`; preserve surviving tuples in original order |
| `DataContainer/CellFeatureData/NumElements` and `Phases` | Class 4: copy the surviving input tuples; feature values are not recomputed |
| Extracted geometry and cell arrays | Class 1 bounding-box dimensions, origin, spacing and literal cell values |

`src/Plugins/SimplnxCore/test/RemoveFlaggedFeaturesTest.cpp` encodes the independent oracle. The eight Class 1 cases use the following fixtures.

| Fixture | Definition | Expected result |
|---|---|---|
| A | 5×2×1; remove features 2 and 3 | Filled IDs `[1,1,1,1,1,1,2,2,2,2]`; distinct-neighbor, single-neighbor, tie and two-iteration copies |
| B | 4×4×1 with five background cells; remove feature 3 | Filled IDs `[0,1,1,1,1,0,2,2,2,2,0,1,2,2,0,0]`; cell 13 copies cell 12, cell 14 copies background cell 15 |
| E | 3×3×3; remove features 3 and 4 | All six face directions; center cell 13 copies +Z cell 22 after a 4-to-2 vote; cell 0 fills in a second iteration |
| Multiple extraction | 12 feature tuples; extract features 3 and 11 | Names end in `-03` and `-11`; each crop has the hand-derived size, origin and cell values |

Fixture B extraction gives dimensions (2,1,1), origin (1,3,0), unit spacing, FeatureIds `[3,3]`, CellValue `[113,114]` and IgnoredValue `[513,514]`. Current tests also assert that the Feature Attribute Matrix is copied unchanged and `tempBounds` is absent from source and output.

The Small IN100 test flags 275 features with fewer than 100 cells. It checks feature compaction, NeighborList deletion, surviving IDs, unchanged-cell renumbering, cell/feature phase agreement and a same-ID face neighbor for each filled cell. It checks 8,535 filled cells and requires surviving-feature growth to equal that count.

The 28 current test cases run in Linux, macOS and Windows in-core CI. All pass in CI at `419f9db35`.

Release exposure was checked in the source at every `upstream/release/v<version>` from v7.0.0 through v7.4.2. The relevant sources are `src/Plugins/SimplnxCore/src/SimplnxCore/Filters/Algorithms/RemoveFlaggedFeatures.cpp`, `src/Plugins/SimplnxCore/src/SimplnxCore/Filters/RemoveFlaggedFeaturesFilter.cpp` and, in v7.4.2, `src/Plugins/SimplnxCore/src/SimplnxCore/utils/FeatureRemovalUtilities.cpp`.

DREAM.3D source at tag `v6.5.171` is `Source/Plugins/Processing/ProcessingFilters/RemoveFlaggedFeatures.cpp` and `Source/Plugins/Sampling/SamplingFilters/ExtractFlaggedFeatures.cpp`. It counts the first neighbor hit and only fills negative IDs (D1/D2 absent). It has no fill-progress or ID-range guard (D3/D4 present), initializes empty bounds to -1 (D6 present), stores bounds privately (D8 absent), and has neither the SIMPLNX Result-based check nor the duplicate warnings (D5/D9 absent).

The current implementation lives in `RemoveFlaggedFeaturesDirect.cpp` and `RemoveFlaggedFeaturesScanline.cpp`, with shared crop delegation in `RemoveFlaggedFeaturesCommon.hpp`. It no longer calls `FeatureRemovalUtilities::removeFlaggedFeatures()`. PR #1736 (`2de2d44db`) contains the V&V fixes and the bounds/warning cleanup. The current extraction tests preserve the source Feature Attribute Matrix in the crops; they do not remove it.
