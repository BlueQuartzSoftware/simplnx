## How it was generated

`make_input.py` (stored beside the file) authors a legacy v7 `.dream3d` directly with h5py using the `legacy_dream3d.D3DLegacyWriter` utility: a 2×2×2 ImageGeom with a Cell AttributeMatrix holding two FeatureIds arrays and three element arrays, plus three CellFeature AttributeMatrices (correctly sized 5- and 3-tuple ones, and a deliberately oversized 10-tuple one for the D1 behavioral check). All values are hand-written constants — no external data, no randomness.

## Canonical oracle output

The oracle is **Class 1 (Analytical)** — the expected outputs are hand-derived in the header of `make_input.py` and duplicated as inline assertions in `test/CreateFeatureArrayFromElementArrayTest.cpp`. The A/B outputs (`output_6_5_171.dream3d`, `output_nx.dream3d`) are compared to each other *and* to these hand values by `compare_ab.py`; neither implementation's output is ever treated as truth.
